Rules: transactions are matched on Account Number, only status DONE is included, and each transaction is dated by its completion time (Updated, UTC), the same way ARIE's existing statements are. Withdrawals = type OUT, deposits = type IN. Descriptions: fees and currency conversions use the Notes text; other payments read "To <recipient>" / "From <sender>", and transfers between a client's own accounts add the destination account. Transfer payment references are not in the export — type them into the description box (new line per line). The opening balance comes from the previous statement's closing balance and is cross-checked against the full transaction history in the file.
